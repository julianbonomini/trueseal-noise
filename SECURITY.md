# Security policy

TrueSeal is a developer preview. Security reports are handled best effort, with no SLA and no bug bounty.

## Reporting a vulnerability

Report a vulnerability through GitHub private vulnerability reporting. Open the Security tab of this repository and choose "Report a vulnerability". Never report a vulnerability in a public issue, pull request or discussion.

The [Reporting a vulnerability](https://trueseal.dev/docs/trust/reporting-a-vulnerability) page on the TrueSeal website states the same policy.

## Fixes and advisories

Fixes, security fixes included, land only in the next 0.x release. Nothing is backported to an older 0.x release. Advisories are published through GitHub Security Advisories.
